# Heading

Section heading within a tab. Renders full-width (no label column).

```php
'section_title' => [
    'type'        => 'heading',
    'title'       => 'Email Settings',       // Or use 'label'
    'description' => 'Configure how emails are sent.',
    'level'       => 'h3',                   // h2, h3, h4, h5, h6
],
```
